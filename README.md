# House Price Prediction — Machine Learning

A beginner-to-intermediate machine-learning project that predicts house prices from property size using supervised regression.

## Objective

Learn the fundamental regression workflow:

`text
Property Data
    ↓
Feature / Target Separation
    ↓
Train/Test Split
    ↓
Regression Model
    ↓
Prediction
    ↓
Evaluation
`

## Concepts Demonstrated

- Supervised learning
- Regression
- Feature and target selection
- Model training
- Prediction
- Basic model evaluation

## Tech Stack

- Python
- Pandas
- NumPy
- scikit-learn
- Jupyter / Python

## Why This Project Exists

This repository represents an early practical step in my machine-learning journey and provides a simple baseline for understanding how a regression model maps an input feature to a continuous target.

**Learning project.**
